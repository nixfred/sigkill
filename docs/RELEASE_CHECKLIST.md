# Release checklist: 0.33.0-prealpha

What is left before the `v0.33.0-prealpha` tag. Prepped already (2026-10-30): the version in `project.godot`, the corners and the window title; the "Linux x86_64" export preset; `tools/export_linux.sh`; `packaging/linux/` (launcher entry, icon, install and uninstall); the README's Download (pre-alpha) section; [the release notes](RELEASE_NOTES-0.33.0-prealpha.md); a privacy sweep of the tree and of what the export packs; the full gate.

Each box below is done in order. **Fred's yes** marks the ones that wait on him; nothing public happens without it.

- [x] **1. Export templates** (Fred's yes: a download). Done 2026-10-30: `Godot_v4.7.2-stable_export_templates.tpz` from the official 4.7.2-stable GitHub release, SHA-512 matching its `SHA512-SUMS.txt`, all 35 files unpacked (2,072,248,588 bytes), `version.txt` reading `4.7.2.stable`. Get the official Godot **4.7.2.stable** export templates from godotengine.org, check them against the release's published SHA-512 sums, and unpack them so that `~/.local/share/godot/export_templates/4.7.2.stable/linux_release.x86_64` exists. `tools/export_linux.sh` names that folder if it is missing.
- [x] **2. Build.** Done 2026-10-30 from `341c182`: `sigkill.x86_64` 75,070,160 bytes; `sigkill-0.33.0-prealpha-linux-x86_64.tar.gz` 29,776,154 bytes, sha256 `97d66c53a5cb0902478635cfe1b567feceee5d1a33c19b6c13c3a7495b0670bb`; the export log has no error or warning line. A rebuild gives a byte-identical binary. `tools/export_linux.sh` on a clean checkout of the release commit. It must end with `ok:` lines for `build/sigkill-0.33.0-prealpha-linux-x86_64.tar.gz` and its `.sha256`, and `build/export.log` must hold no `ERROR` line. The tarball holds one folder with eight files: `sigkill.x86_64`, `LICENSE`, `README.md`, `CREDITS.md`, `sigkill.svg`, `sigkill.desktop`, `install.sh`, `uninstall.sh`.
- [x] **3. - [x] **4. The standing privacy regex over `strings` of the binary and over the unpacked tarball: no home paths, hostnames, user names, process lists, model names, tokens or tailnet addresses.
